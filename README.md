### About

I specialize in Go backend engineering with a focus on high-traffic systems, latency reduction, and predictable production operations.

**Day-to-day focus:**
- **Performance & Profiling:** Tracking down hot allocations with `pprof`, eliminating runtime reflection via build-time code generation, and designing memory-conscious streaming pipelines.
- **Data & Caching:** Multi-tier caching topologies, replica-aware PostgreSQL routing (strict master writes vs. read-replicas), and asynchronous queue-based batching via RabbitMQ.
- **Production Reliability:** Zero-downtime database migrations under live traffic.
